# EarSaver
🛡️ EarSaver Персональный телохранитель твоих барабанных перепонок!  Тихо висит в трее и мониторит звук. Если внезапно врывается орущая реклама на YouTube или игра запускает интро на 100%, утилита моментально приглушает аудиопоток до комфортного уровня.  Забудь про резкие звуки, скримеры и сгоревшие нервы. Береги слух в один клик! 🎧⚡
